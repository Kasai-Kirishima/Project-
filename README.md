# Одержимые — офлайн-прототип RPG

Локальная браузерная игра, которая работает без аккаунта, сервера в интернете и внешних библиотек. Поддерживает ноутбуки и телефоны, интерфейс адаптируется под ширину экрана.

## Быстрый запуск

### Windows
1. Распакуйте ZIP в отдельную папку.
2. Дважды нажмите `start_windows.bat`.
3. В браузере откройте `http://127.0.0.1:8000`.

### macOS / Linux
1. Распакуйте ZIP.
2. Откройте терминал в папке проекта.
3. Выполните `python3 start_server.py`.
4. Откройте `http://127.0.0.1:8000`.

### Телефон
- Можно попробовать открыть `index.html` через файловый менеджер. Если браузер блокирует локальные скрипты или сохранение, используйте локальный сервер.
- На Android можно установить Termux, установить Python, распаковать папку проекта и запустить `python start_server.py`. После этого откройте `http://127.0.0.1:8000` в мобильном браузере.
- Также можно запустить сервер на ноутбуке и открыть с телефона адрес `http://IP-АДРЕС-НОУТБУКА:8000`, если устройства подключены к одной локальной Wi-Fi-сети. Интернет не требуется.

## Сохранения

Прогресс автоматически сохраняется в локальном хранилище текущего браузера. Во вкладке **Система** доступны:
- ручное сохранение;
- экспорт `oderzhimye-save.json`;
- импорт ранее экспортированного файла.

Сохранения на телефоне и ноутбуке независимы. Для переноса используйте экспорт на одном устройстве и импорт на другом.

## Содержание прототипа

- Выбор «Человек» / «Одержимый» с описаниями.
- Анкета: портрет по ссылке или загруженный файл, имя, возраст, рост, вес, характер, биография, страна, фракция, дух, Дар, метка, жильё, автомобиль, оружие и деньги.
- БПСД: 15 человеческих отрядов по четыре человека, 10 смешанных отрядов (три одержимых и человек-командир), три полностью одержимых отряда.
- Орден: фракция только для одержимых. Лидер — Вар, одержимый духом Войны. Участники Ордена начинают в тайном логове.
- 150 обычных людей в базе: 90 сотрудников БПСД и 60 мирных жителей.
- Отдельно 50 одержимых людей и 100 ходячих.
- Схематичная интерактивная карта Берлина с шестью отделами БПСД, районами, улицами, жильём, кафе, ресторанами, боулингом, дартсом, стадионом, достопримечательностями и скрытым логовом Ордена.
- Потребности, деньги, работа для персонажей без фракции, покупки, тренировки и текстовые пошаговые бои. У одержимых есть отдельный расходуемый запас минералов для Даров и регенерации.
- Свободный текстовый ввод с локальным разбором фраз.

## Архитектура

- `index.html` — точка входа.
- `css/styles.css` — весь адаптивный интерфейс.
- `js/data.js` — персонажи, существа, фракционные отряды, работа и места на карте.
- `js/state.js` — состояние игры и сохранения.
- `js/world.js` — карта и перемещение.
- `js/survival.js` — потребности, работа, экономика и тренировки.
- `js/combat.js` — пошаговые бои.
- `js/interpreter.js` — распознавание свободного текста.
- `js/app.js` — анкета, сцены и интерфейс.
- `assets/` — локальные иллюстрации-заглушки.

## Важные ограничения текущей версии

1. Свободный ввод анализируется локальными ключевыми словами и шаблонами. Это не полноценная нейросеть: сложные или неоднозначные фразы могут быть поняты неточно. Внешний ИИ не подключён, поэтому проект остаётся офлайн.
2. Карта Берлина — игровая схема, не точная навигационная карта и не источник реальных маршрутов.
3. Ссылки на внешние изображения персонажей могут не открыться без интернета. В этом случае используются встроенные SVG-иллюстрации; для персонажа можно загрузить изображение с устройства.
4. Это первый играбельный прототип: системы можно расширять независимо, не смешивая данные, интерфейс, экономику и боевую логику.
